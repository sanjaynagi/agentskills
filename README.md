# agentskills

Personal Claude Code skills, packaged as a plugin marketplace.

## Skills

- **build** - condensed engineering-standards lens (planning, style, testing) with an emphasis on avoiding unnecessary complexity and verbose code.
- **human** - rewrites text to be plain, direct, and free of AI-writing tells.
- **scientific-report** - builds a self-contained, theme-aware HTML report in a scientific-paper style: abstract, methods, Hypothesis/Methods/Results sections, numbered captioned tables and figures, superscript citations, and a summary. Includes an HTML template.

## Install

```
/plugin marketplace add sanjaynagi/agentskills
/plugin install agentskills@agentskills
```
